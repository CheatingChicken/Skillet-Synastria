Initial release of ArkInventoryRules_Upgradeable addon.

## Features
- Upgrade chain filtering with 380+ item mappings
- Character-specific attunement detection for upgradeable items
- Account-wide attunement awareness
- Filter rules: upgradeable(), upgradeable("char"), upgradeable("acc")

## Installation
Extract the ArkInventoryRules_Upgradeable folder to your WoW Interface/AddOns directory.

## Requirements
- ArkInventory
- ArkInventoryRules
